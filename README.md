## 📋 Features
- **User-Friendly Interface**: Easy to navigate and intuitive.
- **Wide Range of Products**: Grocery items categorized for quick access.
- **Shopping Cart**: Users can add and remove items seamlessly.
- **Secure Payment Gateway**: Multiple payment options available.

## 🚀 Quick Start Guide
1. **Clone the repository**:
   ```bash
   git clone https://github.com/alishanawal/samsul-grocery.git
   cd samsul-grocery
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the application**:
   ```bash
   npm start
   ```
   Visit `http://localhost:3000` in your browser to see it in action.

## 🛠️ Usage Guide
### For Customers
- Browse through the categories.
- Use the search bar to find specific products.
- Add items to your cart and proceed to checkout.

### For Admins
- Log in to the admin panel to manage products.
- Update stock levels and track orders.
